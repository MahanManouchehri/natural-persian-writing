# Natural Persian Writing

یک Skill برای نوشتن، بازنویسی و بازبینی متن فارسیِ طبیعی، دقیق و متناسب با موقعیت.

این Skill کمک می‌کند متن فارسی در مستندات فنی، Swagger/OpenAPI، رابط کاربری، پیام‌های خطا و پشتیبانی، متن‌های رسمی و حقوقی و گفت‌وگوهای روزمره، ترجمه‌وار یا بیش‌ازحد اداری نباشد؛ بدون این‌که دقت فنی، اصطلاحات پروژه یا معنای امنیتی متن از بین برود.

## چه زمانی استفاده شود؟

- نوشتن یا بازنویسی مستندات فنی و API
- متن‌های UI، پیام‌های خطا و راهنمای کاربر
- پاسخ‌های پشتیبانی و پیام‌های رسمی
- بازبینی متن‌هایی که ساختار جملهٔ انگلیسی در آن‌ها باقی مانده است
- متن‌های قراردادی یا سیاستی که باید ساده، اما دقیق بمانند

## نصب در Codex

محتوای این مخزن را در پوشهٔ Skills خود قرار دهید:

```text
$CODEX_HOME/skills/natural-persian-writing/
```

سپس Codex را دوباره باز کنید یا یک گفت‌وگوی جدید شروع کنید. Skill به‌صورت خودکار هنگام تولید یا اصلاح متن فارسیِ معنادار استفاده می‌شود.

## اصول اصلی

- معنا، اصطلاحات فنی، نام‌های کد، مسیرها، کلیدهای JSON و کدهای وضعیت بدون تغییر می‌مانند.
- لحن متن با مخاطب و محل استفادهٔ آن هماهنگ می‌شود.
- فارسی باید طبیعی، روشن و مستقیم باشد؛ نه ترجمهٔ تحت‌اللفظی و نه بی‌دلیل اداری.
- در متن‌های امنیتی و حقوقی، دقت و حفظ محدودهٔ تعهدها بر ساده‌سازی مقدم است.

برای جزئیات کامل به [SKILL.md](SKILL.md) و [راهنمای نگارش فارسی](references/persian-style-guide.md) مراجعه کنید.
