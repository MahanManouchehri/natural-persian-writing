# Natural Persian Writing

یک Skill عمومی برای تولید، بازنویسی، ترجمه و بازبینی متن فارسیِ طبیعی، دقیق و متناسب با موقعیت.

این Skill فقط برای برنامه‌نویسی نیست. برای نامه و ایمیل رسمی، متن تجاری و تبلیغاتی، ترجمه، محتوای دانشگاهی، متن حقوقی و سیاستی، نوشتهٔ خلاق، گفت‌وگوی روزمره، پیام پشتیبانی، UI و مستندات فنی کاربرد دارد.

## سازگاری با ایجنت‌ها

این مخزن از قالب رایج `SKILL.md` استفاده می‌کند. هر ایجنتی که از Skillهای مبتنی بر `SKILL.md` پشتیبانی می‌کند، می‌تواند آن را از این مخزن نصب و فعال کند.

اگر ایجنت شما سیستم نصب Skill متفاوتی دارد، کافی است فایل `SKILL.md` و پوشهٔ `references/` را در مسیر Skillهای همان ایجنت قرار دهید یا از آن بخواهید محتوای آن‌ها را به دستورهای دائمی خود اضافه کند. هیچ مسیر نصب واحدی برای همهٔ ایجنت‌ها وجود ندارد؛ خود ایجنت باید مسیر و فرایند بومیِ خود را تشخیص دهد.

### پرامپت آماده برای نصب

لینک مخزن را به ایجنت بدهید و این متن را ارسال کنید:

```text
این Skill را از https://github.com/MahanManouchehri/natural-persian-writing نصب کن.
طبق روش استاندارد همین ایجنت، فایل SKILL.md و پوشه references را در محل درست قرار بده، محتوای آن را کامل بخوان و فعال‌بودن آن را بررسی کن.
این Skill باید هنگام نوشتن، بازنویسی، ترجمه یا بازبینی متن فارسیِ معنادار استفاده شود؛ نه صرفاً در کارهای برنامه‌نویسی.
```

## قابلیت‌ها

- نگارش و بازنویسی فارسی طبیعی در هر زمینه
- ترجمهٔ متن به فارسی، با حفظ معنا، لحن، نام‌ها، اعداد و محدودیت‌ها
- نامه و ایمیل رسمی، پیام‌های کسب‌وکاری و محتوای بازاریابی
- متن دانشگاهی، حقوقی، قراردادی و سیاستی با حفظ دقت
- متن خلاق، داستانی و گفت‌وگوی روزمره با لحن متناسب
- پیام‌های رابط کاربری، پشتیبانی و مستندات فنی

## ساختار

```text
natural-persian-writing/
├── SKILL.md
└── references/
    └── persian-style-guide.md
```

برای جزئیات رفتار Skill، [SKILL.md](SKILL.md) را بخوانید. راهنمای تکمیلیِ متن‌های فنی، امنیتی، UI و پشتیبانی در [references/persian-style-guide.md](references/persian-style-guide.md) قرار دارد.
